# Changelog

## 0.1.0 - 2026-10-31

- Add package-owned Apitte controllers with centrally enforced read scopes.
- Add API clients, hashed bearer tokens, expiry, revocation, and client rate limits.
- Add admin client and token grids with separate creation and revocation pages.
- Add CLI commands for non-destructive initial setup and credential management.
- Add typed query validation, collection pagination, and explicit response DTO helpers.
- Add generated OpenAPI documentation and locally served Swagger UI.
